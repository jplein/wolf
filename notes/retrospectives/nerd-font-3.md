# Task 3 of nerd-font: paint GNOME grid and terminal icons from Symbols Nerd Font Mono

Last verified at commit `093d9387766f09951db8d44c01738befc09325e7`.

The task made `CellMetrics::for_font` in `crates/wolf-gnome/src/render.rs` measure the configured family alone and paint with `render::family_list`, which appends `Symbols Nerd Font Mono`. It also made `render::paint` fill a row's backgrounds before its glyphs, and added `tests/symbols_fallback.rs` (T1 to T5) and the cage smoke `tests/smoke_headless/symbols.rs` (T6). The commits are `67dd2de` (code and tests) and `093d938` (documentation).

Eight invocations cost about $26.08 and 77 minutes: `architect-1` $8.08, `test-writer-1` $4.81, `coder-1` $1.80, `architect-2` $1.74, `test-writer-2` $1.36, `coder-2` $1.88, `technical-writer-1` $2.41 and `reviewer-1` $3.99. One round trip, from `coder-1`'s rejection of two tests, added `architect-2`, `test-writer-2` and `coder-2`: about $4.98 and 17 minutes. Every gate passed on both workers on its first run, and review 1 approved with minor notes.

## What went well

- **One constructor owns the font description, so the code change stayed in one file.** `CellMetrics::for_font` is the only place a `pango::FontDescription` is built from the configured family, and the grid, terminal panes, cursor, command-line strip, drawer and toast all read `CellMetrics::font`. Plan 1 §1 found that, `terminal/canvas.rs` needed no code change, and review 1 §1 confirmed no other site. Keep new painters reading `CellMetrics::font` rather than building their own description.
- **The terminal painter was the model for the grid's paint order again.** `terminal::canvas::paint_rows` already fills a row's backgrounds before any glyph, so plan 1 D4 could point `render::paint` at it, and C3b showed the grid test going red without the change. The macOS task found the same in [nerd-font-2](nerd-font-2.md).
- **An existing contract test moved with the feature.** `an_unresolvable_family_still_measures_and_is_not_rewritten` in `tests/paint_golden.rs` pinned the description's family, so T7 needed one changed assertion, and C7a showed it red.
- **`regina on linux` carried every GNOME step.** `test-writer-1` compiled its tests against local stubs on Linux (its commands 3 to 8), and the coders ran 39 Linux commands between them, every falsifier among them. `coder-1` wrapped each falsifier in a scratch script that recorded a `shasum` before the edit and after the restore, and that checksum caught `coder-2`'s loop when it applied no edit.

## What did not go well

- **Plan 1 set unmeasured thresholds, and the round trip came from them.** Plan 1 §4 defined one ink distance with a one-pixel tolerance for both "matches" and "differs", with `DIFFER_MIN` 0.20. At 16 pt the hex box sits inside the solid U+F07B folder, so `coder-1` measured premise P1 at 0.099 in T5 and 0.151 in T3, and P2 at 0.197. Plan 2 kept the tolerant distance for matches and added an exact exclusive-or measure (`ink_xor`, `sy_xor`) for differences; no code changed.
- **No agent before the coder could measure those premises.** `architect-1`'s system prompt grants no `regina on linux`, so it downloaded the fonts to parse their `cmap` tables on macOS and read Pango's source through WebFetch; it was 31% of the task's cost. `test-writer-1` had Linux and stubs but its definition says "Run no test", and it flagged only the cage thresholds as unmeasured. T5's P1 fails on the base `canvas.rs` too, so one stub run would have caught it, as `coder-1`'s report says.
- **The premises panicked one at a time.** `coder-1` could see only the first failing case per run of T3 and T5, and got T3's full table only because its stub run happened to reach P2 first. Plan 2 had premises collected and reported together, which is now in both test files.
- **The ink-mask code is written twice.** `Mask`, `ink_distance` and `ink_xor` in `tests/symbols_fallback.rs` are repeated as `SyMask`, `sy_distance` and `sy_xor` in `tests/smoke_headless/symbols.rs`. Plan 2 §3 had to order the same change in both files, and `test-writer-2` made it twice. `smoke_headless` is its own test binary and does not include `tests/common/`, so nothing gave the two a shared home.
- **zsh's word splitting cost both coders a batch of falsifier runs.** `coder-1` put `cargo test … --exact` in `$T` and passed it unquoted, so zsh handed it over as one word and Linux commands 7 to 11 exited 127 with "command not found". `coder-2`'s first loop over `"C1a E_none" …` split nothing either, and applied no edit. The worker definitions warn about zsh's `=` words and `echo`, but not that an unquoted `$var` is not split.
- **Drift that review 1 found landed.** `crates/wolf-gnome/src/terminal/README.md` line 21 and the `plain_style` doc in `crates/wolf-gnome/src/terminal/canvas.rs` still say a block cursor's plain glyph "cannot overflow the cell", which a symbols icon does. `tests/symbols_fallback.rs` lines 13 and 648 say "the base commit's", wording copied from plan 1's C3b. No present limitation records that a block cursor over an icon redraws its overhang in the cursor's glyph colour.
- **Two tests have a red that no falsifier shows.** Review 1 §3 found that T2 cannot tell "measure the configured family alone" from "measure the family list" on the pinned stack, which plan 1 D3 foresaw. T6's terminal capture was never shown red under cage, because `sy_assert_capture` stops at the editor capture first.
- **The wolf-gnome documents are at their limits again.** The `render.rs` entry of `crates/wolf-gnome/src/README.md` stood at 316 words after the additions, and `technical-writer-1` cut it to 248 of 250, and the `canvas.rs` entry ends at 248. `crates/wolf-gnome/tests/README.md` grew by 2,029 bytes to 110,337, more than twice the size warning.
- **The task instructions named a place the font decisions are not.** They asked for the rationale "in `notes/wolf-gnome/` where the crate's font decisions live", but they live in § Typography of `notes/wolf-gnome-decisions.md`. Plan 1 D8 chose the decisions file and review 1 accepted it, so it cost a paragraph of the plan and no rework.

## Recommendations

1. **Give the architect `regina on linux`.** This is recommendation 1 of [round-3-3](round-3-3.md) and of [round-3-2](round-3-2.md), come up again. Here a scratch Pango painting of the folder and its hex box at 16 pt, run before handoff, would have shown that the plan's distance could not separate them, saving the $4.98 round trip and much of `architect-1`'s font downloading.
2. **Let the test writer run a test's reference-only premises.** This is recommendation 2 of [regina-land-linux-titlebar](regina-land-linux-titlebar.md) and 3 of [round-3-9](round-3-9.md), come up again. In `.claude/skills/regina/agents/test-writer.md`, allow one run against stubs of a test whose premises compare references alone, quoting the values; `test-writer-1`'s stubbed build of T5 would have gone red on P1.
3. **Share the ink-mask helpers.** Move `Mask`, `ink_distance` and `ink_xor` into a module under `crates/wolf-gnome/tests/common/`, include it from `tests/smoke_headless/main.rs` with a `#[path]` module, and delete `SyMask`, `sy_distance` and `sy_xor` from `tests/smoke_headless/symbols.rs`. Plan 2 and `test-writer-2` made the same change twice, and the next measure change would again.
4. **Warn about zsh's word splitting in the worker definitions.** In the zsh paragraph of the definitions under `.claude/skills/regina/agents/`, add that an unquoted `$var` is passed as one word, so a command held in a variable is written as an array, `${=var}`, or run through `sh -c`. It cost `coder-1` five Linux runs and `coder-2` a falsifier loop.
5. **Fix the drift review 1 named.** Reword the block-cursor bullet in `crates/wolf-gnome/src/terminal/README.md` and the `plain_style` doc in `terminal/canvas.rs` to say a text glyph cannot overflow, and add the cursor-over-icon overhang to `notes/wolf-gnome/present-limitations.md`. Replace "the base commit's" at `tests/symbols_fallback.rs` lines 13 and 648 with present-tense wording; the markdown checker's history rule does not reach Rust doc comments.
6. **Show T6's terminal capture red.** In `sy_assert_capture` in `tests/smoke_headless/symbols.rs`, collect the editor capture's failures instead of stopping, so C6a and C6b also show the terminal half. Review 1 §3 found the terminal half able to discriminate but never shown to.
7. **Split the wolf-gnome READMEs.** This is recommendation 6 of [regina-land-toast](regina-land-toast.md) and 7 of [round-3-10](round-3-10.md), come up again. Here the `render.rs` entry needed 68 words cut to take one bullet, and `crates/wolf-gnome/tests/README.md` passed 110,000 bytes.
